# ================================================================================================================
# 脚本功能及特点说明：
# 功能：
# 1. 将固件和不同的参数文件拼接产生各自的固件
# 2. 自动提取tag名和参数文件名，生成对应的固件版本名

# 特点：
# 1. 批量灵活处理 - 拼接的操作由参数文件路径的个数决定，支持多个参数文件一次性处理
# 2. 地址过滤 - 自动移除 address_threshold 地址之后的所有数据,防止固件过大，无法烧录
# 3. 新固件名灵活生成 - 输出的文件命名为[参数文件名]-[tag名].hex，
# 4. 自动删除和覆盖文件 - 直接替换已存在的文件,可选择是否删除主固件同级目录下的其他固件

# ================================================================================================================
