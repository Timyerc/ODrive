PATCH APPLICATION STATUS
========================

The patch has not been fully applied: it targets a different firmware version.
The earlier report claiming completion and a working keep-armed switch was incorrect.
ODRIVE_KEEP_ARMED_ON_ERROR is currently unused and does not change disarm behavior.
Some watchdog and brake-related checks have nevertheless been bypassed.

The previous port referenced an undefined DEFAULT_BRAKE_RESISTANCE. The fallback
has been removed because this version uses brake_resistance = 0 to disable braking.
See PATCH_APPLICATION_SUMMARY.md for the current status.
